# claude-png-unsign

removes the C2PA content credential chunk (`caBX`) from png files generated by Claude.

this is just a morning project and only supports png files. other formats like jpeg and jxl store C2PA data differently ([see here](https://github.com/contentauth/c2pa-rs/tree/c1937f54604b03093a8f8a43538feb169f27703e/sdk/src/asset_handlers)), I didn't bother adding support for those. PRs are open if you want to.

blog post: https://emro.cat/blog/claude-now-tags-its-own-content-heres-how-i-stripped-it

## install

```
git clone https://github.com/notemrovsky/claude-png-unsign.git
cd claude-png-unsign
```

## usage

```
python3 main.py -i input.png -o output.png
```
